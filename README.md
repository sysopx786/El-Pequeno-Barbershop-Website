# El Pequeño Barbershop

Website for **El Pequeño Barbershop** at 603 N 10th St, Reading, PA.

Walk-ins welcome. Unisex. Open seven days. English, Español, and Portuguese.

- **Call:** [(610) 268-9290](tel:+16102689290) or [(484) 794-9965](tel:+14847949965)
- **Text:** [(484) 794-9965](sms:+14847949965)
- **Instagram:** [@elpequenobarbershop01](https://www.instagram.com/elpequenobarbershop01/)
- **TikTok:** [@elpequenobarbershop01](https://www.tiktok.com/@elpequenobarbershop01)
- **Maps:** [Google Maps](https://www.google.com/maps/place/El+Peque%C3%B1o+Barbershop/@40.3445208,-75.9177752,17z)

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:8080](http://localhost:8080).

```bash
npm run build
npm run preview
```

## Stack

React 19, TanStack Start, Vite, Tailwind CSS v4.
